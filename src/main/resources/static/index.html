O que a triagem confere

Portaria de Consolidação MS nº 5/2017, simplificada.

  • T1.1Idade de 16 a 69 anos (16–17 com consentimento; 1ª doação até 60).
  • T1.2Peso mínimo de 50 kg.
  • T1.3Intervalo de 60 dias (homens) ou 90 dias (mulheres).
  • T1.4Até 4 (homens) ou 3 (mulheres) doações em 12 meses.

Release 2 · regras prontas e testadas, entram na triagem quando o cadastro registrar esses dados:

  • T1.6Tatuagem há menos de 12 meses.
  • T1.7Hemoglobina ≥ 13,0 (H) / 12,5 g/dL (M).
  • T1.8Frequência cardíaca de 50 a 100 bpm.
  • T1.9Pressão ≤ 180 × 100 mmHg.

DDD · Parte 3

Seis contextos, um agregado no centro

Cada contexto é um pacote com apresentação, negócio (aplicação + domínio) e dados. O ArchUnit barra na esteira qualquer import que quebre a regra.

Captação · H1

Doador apto ou não

Como atendente, quero saber se o doador está apto para não coletar de quem a norma proíbe.
  • T1.1–T1.4Idade, peso, intervalo e limite anual.

Doação vira bolsa

  • T2.1–T2.435 dias, só apto doa, persistência.
Requisição (core)

Bolsa certa, no prazo

Como esta versão chegou aqui

Nada vai para a main sem pull request, teste verde e aprovação de um colega. O merge publica sozinho.

01 · pull request

GitHub Flow

Branch curta; main protegida com 1 aprovação e sem bypass.

02 · testes

mvn test + verify

Domínio (TDD), ArchUnit, Cucumber da Parte 2, integração com PostgreSQL real e aceitação HTTP.

03 · imagem

Docker multi-stage

Publicada no GHCR com o SHA do commit.

04 · deploy

Render + fumaça

Deploy hook, versão no ar conferida e teste de fumaça nos contextos. Rollback pelo SHA anterior.
